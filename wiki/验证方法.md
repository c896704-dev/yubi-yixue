# 验证方法与回归测试

> 命理引擎的"真值表"是 `lunar-typescript`（历法）与典籍原文（规则）。
> 任何改动必须跑通下列验证，防止回归。

## 1. 四柱排盘回归（对照 lunar-typescript）

```js
import { Solar } from 'lunar-typescript'

// 2026-08-13 10:00 → 丙午年 丙申月 己未日 己巳时
Solar.fromYmdHms(2026, 8, 13, 10, 0, 0).getLunar().getEightChar().getYear() // 丙午

// 立春分界：2026-02-03 仍为乙巳年（立春前），02-04 起丙午年
// 晚子时：2026-08-13 23:30 → 日柱 = 庚申（次日，sect=1 子时归次日），时柱 = 丙子（按次日日干五鼠遁）
// 早子时：2026-08-14 00:30 → 日柱 = 庚申（当日），时柱 = 丙子
// 亥时界：2026-08-13 22:59 → 日柱 = 己未（不进位），时柱 = 乙亥
// 夏令时：1990-06-15 日柱 = 辛亥（1986-1991 夏令时年份不得差天）；
//          1990-06-15 23:30 → 日柱 = 壬子（次日，晚子时进位）
```

## 4. 旺衰计分防重复

构造"日主甲、年干比肩/时干比肩"的命局，断言：
- 年干比肩贡献 ≈ 2（生助维度）
- 时干比肩贡献 ≈ 1.5（仅三围），**不得** 3.5

## 5. 十神统计排除日柱

任意命局断言：`[年,月,时].filter(比劫).length` 与 `[年,月,日,时]` 版本**不同**（后者恒 ≥1）。

## 6. 六爻回归

- 六冲卦：乾为天…兑为泽（8 纯卦）+ 天雷无妄 + 雷天大壮 = 10 卦。
- 六神：甲日初爻=青龙、二爻=朱雀、三爻=勾陈、四爻=腾蛇、五爻=白虎、上爻=玄武。
- 数字起卦：`numberCast(1, -2, -7)` 不得产生负动爻/永不命中。

## 7. 梅花回归

- 时间起卦：2026-08-13（丙午年、农历七月）→ 年支序数=7（午）、农历月=7。
- 综卦：颐/大过/中孚/小过 不得显示"综卦·自身"。
- 错卦：乾坤互错。

## 8. 服务器回归
