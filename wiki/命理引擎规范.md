# 命理引擎技术规范

> 本规范是引擎正确性的"裁判标准"。所有算法模块必须符合下列规则，否则视为 Bug。

## 1. 干支历法（唯一权威：lunar-typescript）

| 项目 | 规则 | 旧实现错误 |
|------|------|-----------|
| 年柱 | 以**立春**为界换年（非元旦） | 手写公式基准年错（2000≠甲子，甲子基准是1984），全年柱错位 |
| 月柱 | 以**节**（立春/惊蛰/清明/立夏/芒种/小暑/立秋/白露/寒露/立冬/大雪/小寒）为界换月；月干用五虎遁 | 节气表用固定近似日期（±1天误差）；五虎遁表整体错位 2 位 |
| 日柱 | 60 甲子循环，跨 1986-1991 中国夏令时年份不得差天 | 用 `Date` 差天数，夏令时年份差 1 天 |
| 时柱 | 五鼠遁；**子时不分早晚，23:00-01:00 为一个完整子时（起于 23 点终于 1 点）；23:00 起即次日之始，日柱进位到第二天**（`EightChar.setSect(1)`，晚子时日柱按明天） | 旧实现 23:00-23:59 时干与八字引擎不一致；库默认 sect=2 晚子时日柱仍算当天，与"23 点为次日之始"的现代习惯不符 |

**结论：四柱一律通过 `lunar-typescript` 的 `Solar.fromYmdHms(...).getLunar().getEightChar()` 计算，禁止手写干支循环表。**

涉及文件：`src/utils/ganzhi.ts`、`src/features/divination/utils/liuyao.ts`（日辰）、`src/features/divination/utils/meihua.ts`（月建）。

## 2. 真太阳时

```
真太阳时 = 北京时间 + (出生地经度 − 120) × 4 分钟 + 均时差(equation of time)
```

- 经度修正：东经 120° 为北京标准时基准；每差 1° = 4 分钟。
- 均时差：全年在 **−14 ~ +16 分钟**之间波动，用经典近似公式
  `EoT = 9.87·sin(2B) − 7.53·cos(B) − 1.5·sin(B)`，B = 2π(N−81)/364，N 为年积日。
- 涉及文件：`src/utils/solarTime.ts`；调用方必须传入出生日期以启用均时差。

## 3. 大运

- 来源：`lunar-typescript` 的 `getYun(genderCode).getDaYun()`。
- **`daYunArr[0]` 是"出生→起运前"的胎运段（干支为空），非真大运**，从 index=1 开始取。
- 起运年龄是**虚岁**（库的 `getStartAge()`），大运每十年一柱：`startAge ~ startAge+9`。
- 当前年龄查找/展示必须统一用虚岁（周岁 + 1）。
- 涉及文件：`src/utils/bazi.ts`、`src/utils/analysis.ts`。

## 5. 旺衰判定（多维度加权）

```
总分 = 月令旺衰(±3) + 地支根气(0~+4) + 天干生助(±5) + 三围生克(±3) + 连锁惩罚(-0~-3) + 寒暖修正(±1)
```

**计分防重复原则：**
- 月干：只在"三围生克"计分（生助维度排除月干）。
- 时干：只在"三围生克"计分（生助维度排除时干）——曾因双计导致时干比劫 +3.5 vs 月干 +2。
- 日支：根气维度已计，三围只补贴身微力。
- 虚浮透干（无根）力量减半。

涉及文件：`src/utils/wangshuai.ts`。

## 7. 命宫 / 胎元（《三命通会》）


## 9. 梅花易数

- 时间起卦（《梅花易数》"年月日时起例"）：
  - 年 = **农历年支序数**（子1…亥12，以立春为界），月/日 = 农历月日，时 = 时支序数（子1…亥12）。
  - 上卦 = (年+月+日) % 8；下卦 = (年+月+日+时) % 8；动爻 = 总和 % 6（余0为6）。
- 字占：动爻 = 总笔画 % 6。
- 错卦：全部爻阴阳翻转；综卦：上下颠倒，**自综卦共 8 个**（乾坤离坎 + 山雷颐、泽风大过、风泽中孚、雷山小过）不显示"综卦=本卦"。
- 涉及文件：`src/features/divination/utils/meihua.ts`。

## 11. 干支作用路线（古籍指南，2026-08-29 新增）

> 作用只有**横竖**，不能斜着。横 = 相邻天干之间 / 地支之间；竖 = 同柱干支之间；异柱干支交叉（斜）不作用。
> 涉及文件：`src/utils/interaction.ts`（作用路线引擎）、`src/utils/wangshuai.ts`（三围计分改造）、`src/utils/chonghe.ts`（检测与展示）。

### 11.1 同柱干支作用（竖向）判定顺序

1. **干支自合四组优先**：丁亥（丁壬合主气）、辛巳（丙辛合主气）、癸巳（戊癸合中气）、己亥（甲己合余气）
   - 丁亥/辛巳：合主气力纯 → **地支直接克天干（截脚）**定案
   - 癸巳/己亥：合中余气力弱 → 按力量辨方向：天干不太弱（有根或月令不死囚）→ **天干克地支（盖头）**；天干太弱（无根且月令死囚）→ 地支克天干
2. 干支同五行 → 比和（坐根）
3. **地支生天干**：默认成立，两个条件例外——
   - **燥土不生金**：日支为土、日主为金、月令在巳午未三个月且局中无水调候 → 不生（反脆金）
   - **寒水不生木**：日支为水、日主为木、月令在亥子丑三个月且局中无丙丁火暖局 → 不生（反冻木）
4. 天干生地支：直接成立（竖向泄）
5. **天干克地支（盖头）**：直接成立；特例 **甲戌克力打折**（甲又贪生戌中丁火，又生又克贪生忘克，系数 0.5）
6. 地支克天干（非自合）→ **无作用**（地支不能直接克天干）

### 11.2 同柱优先（盖头截脚减力）

月干/时干与日主横向作用时，若其自身同柱存在盖头（干克支）、自合截脚（自合-支克干/弱）、自合盖头（自合-干克支），天干力量先被同柱消耗 → 对日主作用力 ×0.5。

### 11.3 天干横向作用（相邻才有，隔位不作用）

- 天干五合：甲己土、乙庚金、丙辛水、丁壬木、戊癸火（只论年-月、月-日、日-时相邻对）
- 天干四冲：甲庚、乙辛、丙壬、丁癸

### 11.4 三刑正名（修复旧命名颠倒）

**寅巳申 = 无恩之刑**（恩将仇报）、**丑戌未 = 恃势之刑**（恃势凌人）、子卯 = 无礼之刑、辰午酉亥 = 自刑。旧实现两组正好写反。

### 11.5 六破

子酉、丑辰、寅亥、卯午、巳申、戌未（冲之轻者；寅亥、巳申既合又破）。

### 11.6 墓库

- 四库归属：**辰=水库、戌=火库、丑=金库、未=木库**（土旺于四季另论）
- 十干墓（阳生阴死顺行，与十二长生表一致）：甲未、乙戌、丙戊墓戌、丁己墓丑、庚墓丑、辛墓辰、壬墓辰、癸墓未
- **旺为库、衰为墓**（库神五行能量 ≥8 为库、≤3 为墓）
- 开库：辰戌冲 / 丑未冲为**冲开**；入丑戌未三刑组为**刑开**（古法库须刑冲而开）
- **透干出库**（子平法）：库神五行透出天干方能起用
- 《三命通会》自库说：壬水墓辰、辛金墓丑为自库，**不忌刑冲**

## 12. 人生轨迹板块（识人术扩展，2026-09-08 新增）

架构：代码逻辑为辅（引擎算事实）、AI 解读为主（叙事展开）。**与"人品性格分析"三重隔离**：数据表隔离（`nayinTrajectory.ts` 不复用 `NAYIN_XIANG/NAYIN_SHADOW`）、显示隔离（报告下方独立 `<section class="tj-report">`）、AI 输出流隔离（`generateTrajectoryInsight` 独立 prompt/独立状态机/独立存储列 `trajectory_insight`，与 `ai_insight` 并发写互不覆盖）。

### 12.1 双轴时间骨架

- **限运四段轴**（《三命通会》主流口径，联网三源核验）：年柱 1-16（根·祖业环境/少年神气）→ 月柱 17-32（苗·求学境遇/人格初成）→ 日柱 33-48（花·中年处境/婚姻人际）→ 时柱 49+（果·世俗结局/沉淀气质）。另有 15/30/45 岁分段流派，写入披露不作废。
- **大运轴**：全部大运（约 9 步）逐列可点选，点选展开该运十年逐年流年。大运起止**必须用 lunar-typescript `DaYun.getStartYear()/getEndYear()`**（已透传进 `BigFortune.startYear/endYear`）——用 `person.birthYear + startAge - 1` 反推在晚子时/年初出生会偏 ±1 年（dayOffset 改基准年）。
- **八信息→轨迹语义**（用户定义）：胎息=元神画像、胎元=遗传本能禀赋、命宫=立身舞台精神追求、身宫=落地果实后天所得；各配盲派克应（胎元受冲=奔波、胎元冲年=父母不全、胎元空=体弱财散、身命空=隐逸/财不聚、身命遇合=贵人）。

### 12.2 岁运事实检测（relation.ts，核心不变式）

**外部干支（大运/流年）× 带标签目标（四支+三垣+胎息）只配 (ext, target) 对；natal↔natal 永不在此配对**——这是与 `getChongHeAnalysis`（四支集合语义）的分水岭：塞进集合会把原局内部刑冲在每一步岁运重复计入，且自刑/三刑用 `includes` 判定会对 natal 既有双支假阳性。

关系集：伏吟（支同字；三垣同标签的支层与柱层重复在 decorateFacts 合并）、反吟=天干四冲∧地支六冲、天克地冲、天合地冲（顺中转逆）、天冲地合（败中有成）、双合（绊）、六冲/合/害/破、三合（ext+2 natal 成局；含中神=半合；缺中神=拱局，措辞避开已占用的"暗合"）、三刑（ext 为引动者）、干合日主（晦气）、五合、天干四冲、天干比叠。

流年附加：岁运并临（流年干支=本运干支）、太岁空亡（日柱旬空口径）、日主入墓（十二长生查"墓"）、冲开墓库（流年冲 natal 四库支）、藏干透出（盲派神出法：流年干=原局某支所藏→该十神引动）。

### 12.3 大运/流年档案（核验依据）

- 纳音×本命得地档（《三命通会·论大运》"纳音与命相孚同类最爲上吉、财官次之、泄气受克不吉"）：同气上吉/运生命得地/命克运财官/命生运泄气/运克命受克。年命、日柱命双口径并列。
- 十二长生入运（《论大运》原文分档）：长生创建、临官帝旺兴盛、衰病退败、死绝蹇塞、沐浴落魄防酒色、胎库冠带平稳。阴干从阳顺阴逆说（与 wangshuai.ts 同口径），阴干档视作弱信号。
- 运柱干支形：盖头（干克支）/截脚（支克干）/同气/相生——统看十年为主，"前五后五"另派披露。
- **具体度口径**（用户拍板）：术语+宫位事象+年龄区间三件套；古籍冲伏皆须分喜忌，本模块不做喜忌判定→断语保留双向可能（"冲动婚姻宫——是拆是建须合本命看"），禁编造具体事件/百分比。
- 流年干支取法：`Solar.fromYmd(y,6,1).getLunar().getYearInGanZhi()` 年中取值（与立春口径年内除 1-2 月外恒同），与项目既有 liuNian 取法一致。

### 12.4 数据流铁律

- **TrajectoryResult 派生数据不落库**（80 年事实 JSON 200KB+/条，会打爆 GET LIMIT 200 列表接口）；只缓存 `trajectoryInsight` 纯文本。旧记录打开时以 person 现场重算，查询年注入 `nowYear`（引擎纯函数，isCurrent/keyMoments 以它锚定；prompt 禁止写"今年是X年"）。
- **AI 双写并发安全**：服务端 `PATCH /renshi/records/:id/ai` 按字段白名单写（`{aiInsight:'ai_insight', trajectoryInsight:'trajectory_insight'}`，列名绝不拼接请求值）；POST 全量 upsert 对两 AI 列用 COALESCE 保护；GET 必须返回 trajectory_insight（否则 merged 读回会抹掉本地新字段）；本地读改写放同一 readwrite 事务。
- 序列化进 prompt 的只有：四段摘要 + 每运档案 + keyMoments top-25（权重排序：伏吟/反吟/岁运并临/天克地冲/空亡/冲库 ≥7 > 三合 ≥6 > 半合/合害/透干 ≥4 > 拱/破 ≥2）；逐年明细只活在 UI 内存。
`TrajectoryResult` 相关模块：`src/utils/relation.ts`（关系表+扫描原语）、`src/utils/nayinTrajectory.ts`（轨迹数据层）、`src/utils/trajectory.ts`（引擎）、`src/features/renshi/TrajectorySection.tsx`（UI）。回归：`src/utils/__tests__/trajectory.test.ts` 47 用例。
