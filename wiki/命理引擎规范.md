# 命理引擎技术规范

> 本规范是引擎正确性的"裁判标准"。所有算法模块必须符合下列规则，否则视为 Bug。

## 1. 干支历法（唯一权威：lunar-typescript）

| 项目 | 规则 | 旧实现错误 |
|------|------|-----------|
| 年柱 | 以**立春**为界换年（非元旦） | 手写公式基准年错（2000≠甲子，甲子基准是1984），全年柱错位 |
| 月柱 | 以**节**（立春/惊蛰/清明/立夏/芒种/小暑/立秋/白露/寒露/立冬/大雪/小寒）为界换月；月干用五虎遁 | 节气表用固定近似日期（±1天误差）；五虎遁表整体错位 2 位 |
| 日柱 | 60 甲子循环，跨 1986-1991 中国夏令时年份不得差天 | 用 `Date` 差天数，夏令时年份差 1 天 |
| 时柱 | 五鼠遁；23:00-23:59 按"晚子时"约定（与八字引擎同款库保持一致） | 23:00-23:59 时干与八字引擎不一致 |

**结论：四柱一律通过 `lunar-typescript` 的 `Solar.fromYmdHms(...).getLunar().getEightChar()` 计算，禁止手写干支循环表。**

涉及文件：`src/utils/ganzhi.ts`、`src/features/divination/utils/liuyao.ts`（日辰）、`src/features/divination/utils/meihua.ts`（月建）。

## 2. 真太阳时

```
真太阳时 = 北京时间 + (出生地经度 − 120) × 4 分钟 + 均时差(equation of time)
```

- 经度修正：东经 120° 为北京标准时基准；每差 1° = 4 分钟。
- 均时差：全年在 **−14 ~ +16 分钟**之间波动，用经典近似公式
  `EoT = 9.87·sin(2B) − 7.53·cos(B) − 1.5·sin(B)`，B = 2π(N−81)/364，N 为年积日。
- 涉及文件：`src/utils/solarTime.ts`；调用方必须传入出生日期以启用均时差。

## 3. 大运

- 来源：`lunar-typescript` 的 `getYun(genderCode).getDaYun()`。
- **`daYunArr[0]` 是"出生→起运前"的胎运段（干支为空），非真大运**，从 index=1 开始取。
- 起运年龄是**虚岁**（库的 `getStartAge()`），大运每十年一柱：`startAge ~ startAge+9`。
- 当前年龄查找/展示必须统一用虚岁（周岁 + 1）。
- 涉及文件：`src/utils/bazi.ts`、`src/utils/analysis.ts`。

## 5. 旺衰判定（多维度加权）

```
总分 = 月令旺衰(±3) + 地支根气(0~+4) + 天干生助(±5) + 三围生克(±3) + 连锁惩罚(-0~-3) + 寒暖修正(±1)
```

**计分防重复原则：**
- 月干：只在"三围生克"计分（生助维度排除月干）。
- 时干：只在"三围生克"计分（生助维度排除时干）——曾因双计导致时干比劫 +3.5 vs 月干 +2。
- 日支：根气维度已计，三围只补贴身微力。
- 虚浮透干（无根）力量减半。

涉及文件：`src/utils/wangshuai.ts`。

## 7. 命宫 / 胎元（《三命通会》）

```
命宫地支：命宫 = 14 − (月支数 + 时支数)；和 > 14 时用 26 − 和（子=1…亥=12）
         例：子月子时 → 亥；寅月午时 → 卯
```

## 9. 梅花易数

- 时间起卦（《梅花易数》"年月日时起例"）：
  - 年 = **农历年支序数**（子1…亥12，以立春为界），月/日 = 农历月日，时 = 时支序数（子1…亥12）。
  - 上卦 = (年+月+日) % 8；下卦 = (年+月+日+时) % 8；动爻 = 总和 % 6（余0为6）。
- 字占：动爻 = 总笔画 % 6。
- 错卦：全部爻阴阳翻转；综卦：上下颠倒，**自综卦共 8 个**（乾坤离坎 + 山雷颐、泽风大过、风泽中孚、雷山小过）不显示"综卦=本卦"。
- 涉及文件：`src/features/divination/utils/meihua.ts`。

## 11. 干支作用路线（古籍指南，2026-08-29 新增）

> 作用只有**横竖**，不能斜着。横 = 相邻天干之间 / 地支之间；竖 = 同柱干支之间；异柱干支交叉（斜）不作用。
> 涉及文件：`src/utils/interaction.ts`（作用路线引擎）、`src/utils/wangshuai.ts`（三围计分改造）、`src/utils/chonghe.ts`（检测与展示）。

### 11.1 同柱干支作用（竖向）判定顺序

1. **干支自合四组优先**：丁亥（丁壬合主气）、辛巳（丙辛合主气）、癸巳（戊癸合中气）、己亥（甲己合余气）
   - 丁亥/辛巳：合主气力纯 → **地支直接克天干（截脚）**定案
   - 癸巳/己亥：合中余气力弱 → 按力量辨方向：天干不太弱（有根或月令不死囚）→ **天干克地支（盖头）**；天干太弱（无根且月令死囚）→ 地支克天干
2. 干支同五行 → 比和（坐根）
3. **地支生天干**：默认成立，两个条件例外——
   - **燥土不生金**：日支为土、日主为金、月令在巳午未三个月且局中无水调候 → 不生（反脆金）
   - **寒水不生木**：日支为水、日主为木、月令在亥子丑三个月且局中无丙丁火暖局 → 不生（反冻木）
4. 天干生地支：直接成立（竖向泄）
5. **天干克地支（盖头）**：直接成立；特例 **甲戌克力打折**（甲又贪生戌中丁火，又生又克贪生忘克，系数 0.5）
6. 地支克天干（非自合）→ **无作用**（地支不能直接克天干）

### 11.2 同柱优先（盖头截脚减力）

月干/时干与日主横向作用时，若其自身同柱存在盖头（干克支）、自合截脚（自合-支克干/弱）、自合盖头（自合-干克支），天干力量先被同柱消耗 → 对日主作用力 ×0.5。

### 11.3 天干横向作用（相邻才有，隔位不作用）

- 天干五合：甲己土、乙庚金、丙辛水、丁壬木、戊癸火（只论年-月、月-日、日-时相邻对）
- 天干四冲：甲庚、乙辛、丙壬、丁癸

**寅巳申 = 无恩之刑**（恩将仇报）、**丑戌未 = 恃势之刑**（恃势凌人）、子卯 = 无礼之刑、辰午酉亥 = 自刑。旧实现两组正好写反。

### 11.6 墓库

- 四库归属：**辰=水库、戌=火库、丑=金库、未=木库**（土旺于四季另论）
- 十干墓（阳生阴死顺行，与十二长生表一致）：甲未、乙戌、丙戊墓戌、丁己墓丑、庚墓丑、辛墓辰、壬墓辰、癸墓未
- **旺为库、衰为墓**（库神五行能量 ≥8 为库、≤3 为墓）
- 开库：辰戌冲 / 丑未冲为**冲开**；入丑戌未三刑组为**刑开**（古法库须刑冲而开）
- **透干出库**（子平法）：库神五行透出天干方能起用
- 《三命通会》自库说：壬水墓辰、辛金墓丑为自库，**不忌刑冲**
