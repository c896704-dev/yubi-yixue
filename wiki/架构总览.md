# 项目架构总览

## 1. 技术栈

| 层 | 技术 | 说明 |
|----|------|------|
| 前端 | React 18 + TypeScript + Vite 6 + Tailwind CSS 3 | 单页应用，5 大功能 Tab |
| 后端 | Express 4 (ESM) + better-sqlite3 (WAL) | REST API，端口 3002 |
| 本地存储 | IndexedDB | 离线可用，登录后迁移到服务端 |
| AI | DeepSeek（主）+ 通义千问（备） | 规则引擎先行 + AI 叙事润色 |
| 历法 | lunar-typescript ^1.6.12 | 全项目干支/农历/节气权威来源 |

## 2. 前端功能模块

```
App.tsx（Tab 路由）
├── features/bazi      八字排盘（排盘→旺衰→格局→用神→神煞→AI报告）
├── features/compat    双人合盘（双方八字 + 多维度评分）
├── features/fengshui  风水分析（九宫飞星 + 户型几何 + AI评估）
├── features/divination 算卦（六爻纳甲 + 梅花易数）
└── features/almanac   万年历（农历/干支/节气/宜忌）
```

## 3. 核心引擎分层

**规则引擎先行，AI 只做叙事润色**（保证命理结论有数据锚点）：

```
utils/bazi.ts         八字排盘 + 大运 + 格局（正八格/从格/专旺格/化气格）
  ├── 依赖 lunar-typescript 排四柱、大运（getYun/getDaYun）
  ├── 自研：建禄/月刃表、格局判定、五行能量分布
utils/wangshuai.ts    旺衰判定（月令+根气+生助+三围+连锁惩罚+寒暖修正）
utils/yongshen.ts     喜用神四维加权（扶抑+调候+通关+病药）
utils/shensha.ts      30+ 神煞（天乙/天德/月德/文昌/桃花/驿马/华盖…）
utils/chonghe.ts      刑冲合害 + 胎元 + 命宫（《三命通会》公式）
utils/analysis.ts     六大叙事报告（Markdown → AI 润色）
```

## 4. 数据流

```
用户输入 → PersonInfo（出生年月日时/性别/经度）
  → calculateBazi()        （真太阳时修正 → lunar-typescript 排四柱）
  → calculateBigFortunes() （起运虚岁 + 每十年一柱）
  → judgeBodyStrength() / determineYongShen() / calculateShenSha()
  → renderXXXReport() → AI 润色 → 展示
```

## 5. 部署

- 生产站点：`yubiyixue.xyz`（自建 VPS + Nginx，`NODE_ENV=production`）
- Docker：`Dockerfile`（node:20-alpine，构建产物 `dist/` + `server/`）
- 源码仓库：`github.com/c896704-dev/yubi-yixue`

## 6. 重要约定

- **四柱/干支的唯一权威来源是 lunar-typescript**（节气、立春、晚子时全部交给库处理）；
  任何手写干支表都曾引入过系统性错误（见[问题修复记录](问题修复记录.md)）。
- 大运年龄一律为**虚岁**（库的 `DaYun.getStartAge()` 语义），展示与查找必须统一。
- 十神统计（比劫/财/印/杀计数）**必须排除日柱**（日柱十神恒为"比肩"）。
